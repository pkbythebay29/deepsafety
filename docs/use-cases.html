Use Cases

Application patterns for real Deep Safety integrations.

These examples show how the API can be composed in products, field tools, notebooks, and agent workflows without flattening the modeling chain.

API Reference Tutorials Use Cases README

Use Case

Pipeline leak impact screening

A map-based application allows an engineer to drop a pin on a gas line, define pressure, temperature, flow, geometry, and leak type, then generate an impact zone and receptor screening result. 

materials -> scenario/select -> gas-pipe -> dispersion -> gis/impact-zones

Use Case

Toxic gas release planning

An application can take a stored chlorine or ammonia record, calculate a worst-case or realistic release, compare predicted concentrations to AEGL or ERPG values, and render contour payloads for site planning.

Core routes: /materials, /source-models/*, /dispersion/*, /toxic-criteria/lookup, /visualization/solve

Use Case

Field sign analysis from a photo

A user walking a site or corridor can capture a sign, pass the text or OCR output to the sign-analysis endpoint, and receive a seeded Deep Safety workflow that suggests relevant scenarios and inputs.

Core route: POST /signs/analyze

Use Case

HAZOP support with linked consequence outputs

Use the same material, source, and consequence outputs to populate a HAZOP note set so the team is not manually copying disconnected values between tools.

Core routes: /source-models/*, /dispersion/*, /effect-models/solve, /hazard-evaluation/hazop

Use Case

Notebook-driven safety studies

Teams can use Jupyter to compare multiple scenarios, sweep hole size, pressure, or meteorology, and generate plots or reports from one install target.

Why it works: the same package, constants registry, and model contract are available in notebooks and in the API.

Use Case

Agent-driven process safety tooling

Since the MCP bridge exposes the same model surface, agents can query materials, propose a scenario, run source and dispersion calculations, and explain results with the same equations and constant metadata shown to human users.

Core interfaces: HTTP API, Python package, and deepsafety-mcp

Tutorials

Training guides for package users, API integrators, and browser users.

These tutorials are designed to shorten the time between first install and a working application. Each guide is intentionally practical and follows the same model chain used by the API itself.

Quick Start

Get to first result in ten minutes

Install the package, inspect available materials, select a scenario, run a source calculation, and feed the result into dispersion. 

pip install deepsafety

from deepsafety import DeepSafetyClient

client = DeepSafetyClient("http://127.0.0.1:8000")
materials = client.list_materials("chlorine")
scenario = client.select_release_scenario({
    "scenarioType": "worst_case",
    "equipmentType": "pipe",
    "inventoryMass": 2500,
    "siteTopography": "urban"
})

API Workflow

Build an API-first consequence workflow

Use materials as the upstream selector, then call source, then dispersion, then effect or hazard-evaluation endpoints. 

1. GET /materials/{materialId}
2. POST /source-models/scenario/select
3. POST /source-models/gas-pipe
4. POST /dispersion/gaussian-plume
5. POST /effect-models/solve or /hazard-evaluation/*

Scenario Training

Understand realistic versus worst-case assumptions

Deep Safety keeps realistic, worst-case, and conservative analysis explicit because those are modeling decisions, not hidden defaults.

Choice Typical intent When to use
realistic_case Site-informed screening Operational planning and scenario comparison
worst_case Highly conservative screening Regulatory-style bounding cases and outer envelopes
conservative-analysis Intentional overprediction of the source term Safety margin studies and rapid screening

Browser-Local

Use the Pages app without an external backend

The browser-local runtime is useful for demos, lightweight screening, and embedded tools that should work directly on GitHub Pages. 

const result = await window.DeepSafetyBrowserApi.request(
  "POST",
  "/gis/impact-zones",
  {
    scenarioType: "leak",
    source: { latitude: 52.52, longitude: 13.405 },
    config: { released_mass_kg: 50, threshold_kg_m3: 0.02 }
  }
);

Use the packaged client or the local notebook examples to inspect model metadata, constants, and response payloads before wiring the models into a larger application.

Integration Pattern

Show equations and constants in your own UI

Deep Safety is intended to make the model transparent to the end user. Pull the service catalog and present equations, constants, and physical meanings alongside the form fields that drive them.

Tip: combine GET /service-catalog with the module-specific endpoints so the UI shows the actual equation and the physical meaning of each constant near the results.

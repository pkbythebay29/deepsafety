README

Deep Safety at a glance.

This page mirrors the repository README in a web-friendly format so users can understand installation, runtime options, and the current feature set before they integrate Deep Safety into their own tools.

What it is

Deep Safety is a process safety consequence-analysis platform with one install target, one API contract, and multiple execution modes: Python package, FastAPI service, browser-local runtime, GitHub Pages application, Jupyter notebook, and MCP bridge.

Implemented layers

  • Scenario definition engine
  • Scenario library
  • Source model service
  • Dispersion modeling service
  • Fire and explosion modeling service
  • Effect modeling service
  • Visualization layer

Package and runtime

pip install deepsafety
pip install "deepsafety[jupyter]"

deepsafety-api
deepsafety-mcp
python -m deepsafety

Deployment options

  • GitHub Pages for the static web experience
  • Docker container for the FastAPI service
  • Local Python install for notebooks and scripts
  • MCP server for tool-driven and agent-driven use

Container quick start

docker build -t deepsafety .
docker run --rm -p 8000:8000 deepsafety

# or
docker compose up --build

Notebook entry point

Use notebooks/deepsafety_explorer.ipynb or import the package directly in Jupyter for model discovery and quick calculations.

Current model coverage

Aligned with the repository state as of this build.

Source and dispersion

  • Gas release: choked, non-choked, pipe, hole, relief, vessel blowdown
  • Liquid release: tank hole, pipe flow, gravity-driven, pressure-driven
  • Flashing and two-phase screening
  • Pool formation and evaporation screening
  • Gaussian plume, Gaussian puff, dense-gas screening

Hazards and effects

  • Jet fire, pool fire, fireball BLEVE
  • TNT equivalency, multi-energy, VCE
  • Toxic, thermal, and explosion probit models
  • Toxic, thermal, and explosion dose-response curves
  • Population-based expected cases from effect models

For exact endpoint contracts use API Docs. For the interactive experience use the app.
